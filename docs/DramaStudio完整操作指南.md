## 项目简介

**DramaStudio** 是一个本地 AI 短剧生成工具，可以帮你从故事梗概自动生成完整的短剧视频。

### 核心功能

- ✅ **故事生成**：输入梗概，AI 自动生成多集剧本
- ✅ **角色生成**：AI 提取角色列表，自动生成角色形象图
- ✅ **场景生成**：从剧本自动提取场景，生成场景背景图
- ✅ **分镜生成**：按集自动生成分镜脚本（含景别/运镜/台词）
- ✅ **图片/视频生成**：逐镜生成静帧图与视频片段
- ✅ **合成视频**：所有分镜视频自动合成为完整剧集文件

### 技术架构

```
DramaStudio/
├── backend-node/          # Node.js 后端（Express + SQLite）
├── frontweb/              # Vue 3 前端（Vite + Element Plus）
├── desktop/               # Electron 桌面客户端
```

## 环境准备

### 系统要求

- **操作系统**：Windows 10/11
- **Node.js**：>= 18.0.0
- **内存**：>= 8GB（推荐 16GB）
- **硬盘**：>= 10GB 可用空间

### 依赖安装

#### 1. 安装 Node.js

访问 https://nodejs.org/ 下载并安装 Node.js 18 或更高版本。

验证安装：
```bash
node --version
npm --version
```

#### 2. 克隆项目

```bash
git clone https://github.com/liruiqing76/DramaStudio.git
cd DramaStudio
```

#### 3. 安装后端依赖

```bash
cd backend-node
npm install
```

#### 4. 安装前端依赖

```bash
cd ../frontweb
npm install
```

## 启动服务

### 方式一：一键启动（推荐）

双击项目根目录的 `run_dev.bat` 文件，会自动启动前端和后端服务。

### 方式二：手动启动

#### 1. 启动后端服务

```bash
cd backend-node
npm start
```

**成功标志**：
```
✅ DramaStudio API listening on port 5679
```

**测试后端**：
```bash
curl http://localhost:5679/health
```

预期返回：
```json
{
  "status": "ok",
  "app": "DramaStudio API",
  "version": "1.0.0"
}
```

#### 2. 启动前端服务（新开终端）

```bash
cd frontweb
npm run dev
```

**成功标志**：
```
✅ VITE v5.0.0  ready in 500 ms
✅ Local:   http://localhost:3013/
```

#### 3. 访问前端界面

打开浏览器，访问 `http://localhost:3013`

## 完整操作流程

### 📝 流程概览

```
配置AI服务 → 创建项目 → 生成故事 → 生成角色 → 生成场景 
    ↓
进入制作 → 生成分镜 → 生成分镜图 → 生成分镜视频 → 合成最终视频
```

---

### 步骤 1：配置 AI 服务

**位置**：首页 → 点击"AI 配置"

#### 1.1 文本生成服务配置

用于生成故事剧本、分镜脚本等文本内容。

**推荐配置**：
- **服务商**：阿里云 DashScope（通义千问）
- **API Key**：你的通义千问 API Key
- **模型**：qwen-max 或 qwen-plus

**获取 API Key**：
1. 访问 https://dashscope.aliyun.com/
2. 注册并登录
3. 进入"API Key 管理"
4. 创建新的 API Key

**测试连接**：
1. 填写 API Key
2. 点击"测试连接"按钮
3. 看到"连接成功"提示

#### 1.2 图片生成服务配置

用于生成角色形象图、场景背景图、分镜图片。

**推荐配置**：
- **服务商**：阿里云 DashScope（通义万相）
- **API Key**：同上（通义千问 API Key）
- **模型**：wanx-v1 或 wanx-v2

**测试连接**：
1. 填写 API Key
2. 点击"测试连接"按钮
3. 看到"连接成功"提示

#### 1.3 视频生成服务配置

用于生成分镜视频片段。

**选项 A：使用在线服务（推荐）**

当前视频生成聚焦三家主力模型：

| 服务商 | 推荐模型 | 说明 |
|--------|----------|------|
| 阿里云 DashScope | `wan3.0-i2v` / `wan3.0-kf2v` / `wan3.0-t2v` / `wan3.0-r2v` | 图生视频 / 首尾帧 / 文生视频 / 参考图 |
| MiniMax（海螺） | `MiniMax-Hailuo-03` / `MiniMax-Hailuo-03-Fast` | 图生视频 |
| Agnes AI | `agnes-video-2.5-flash` / `agnes-video-2.5` | 文生视频 / 关键帧 / 参考图，推荐主力 |

**获取 API Key**：
1. 访问 https://www.volcengine.com/product/doubao
2. 注册并登录
3. 进入"API 管理"
4. 创建新的 API Key


#### 1.4 保存配置

配置完成后，点击"保存配置"按钮。

**配置文件位置**：
```
Windows: C:\Users\你的用户名\AppData\Roaming\DramaStudio\backend\configs\config.yaml
```

### 步骤 2：创建新项目

**位置**：首页 → 点击"新建项目"

#### 2.1 填写项目信息

| 字段 | 说明 | 示例 |
|------|------|------|
| 项目名称 | 短剧的名称 | "武侠传奇" |
| 画面比例 | 视频的画面比例 | 16:9（横屏）或 9:16（竖屏） |
| 生成风格 | AI 生成图片的艺术风格 | 写实风格、动漫风格、水墨风格等 |

#### 2.2 创建项目

1. 填写完项目信息
2. 点击"创建"按钮
3. 系统自动进入"剧集管理"页面

**注意事项**：
- 画面比例创建后无法修改
- 生成风格可以后续在 AI 配置中修改

---

### 步骤 3：生成故事剧本

**位置**：剧集管理页面 → 点击"生成故事"

#### 3.1 输入故事梗概

在文本框中输入故事梗概，例如：

```
一个年轻的武侠弟子，在山林中偶遇一位神秘老人，
学到了绝世武功，最终成为一代大侠的故事。
```

**建议**：
- 梗概长度：100-500 字
- 包含主要角色、核心冲突、结局
- 避免过于复杂的内容（首次测试建议简单故事）

#### 3.2 选择生成参数

| 参数 | 说明 | 建议 |
|------|------|------|
| 生成集数 | 要生成的集数（1-6集） | 首次测试选 1 集 |
| 生成风格 | 剧本的写作风格 | 与项目设置一致 |

#### 3.3 生成剧本

1. 点击"生成"按钮
2. 等待 AI 生成剧本（约 1-2 分钟）
3. 生成完成后，可以看到：
   - 分集列表（左侧）
   - 每集的剧本内容（右侧）

**剧本内容包含**：
- 集号
- 集名
- 场景列表
- 每个场景的：
  - 场景描述
  - 角色对白
  - 动作描述
  - 镜头提示

#### 3.4 编辑剧本（可选）

如果对已生成的剧本不满意，可以：

1. **手动编辑**：直接在剧本文本框中修改
2. **重新生成**：点击"重新生成"按钮，AI 会生成新的剧本
3. **修改梗概**：返回上一步，修改故事梗概后重新生成

---

### 步骤 4：生成角色

**位置**：剧集管理页面 → 点击"角色"标签页

#### 4.1 提取角色

1. 点击"提取角色"按钮
2. AI 会自动从剧本中提取角色列表
3. 提取完成后，可以看到角色卡片列表

**角色卡片包含**：
- 角色名称
- 角色描述
- 角色图片（未生成时为占位图）

**常见问题**：
- 如果角色提取不完整，可以手动添加角色
- 点击"添加角色"按钮，填写角色信息

#### 4.2 生成角色图片

1. 逐个点击角色卡片上的"生成图片"按钮
2. 系统会调用图片生成服务，生成角色形象图
3. 每个角色生成时间约 30秒-1分钟

**生成参数**（可在 AI 配置中设置）：
- 图片尺寸：与项目画面比例一致
- 艺术风格：与项目生成风格一致
- 角色描述：AI 会根据角色描述生成图片

#### 4.3 选择满意的角色图片

1. 每个角色可以生成多张图片
2. 点击角色卡片，可以看到生成的所有图片
3. 选择最满意的一张，点击"设为主图"

**注意事项**：
- 角色图片会用于后续的分镜生成
- 建议选择清晰、符合角色设定的图片

**生成参数**（可在 AI 配置中设置）：
- 图片尺寸：与项目画面比例一致
- 艺术风格：与项目生成风格一致
- 场景描述：AI 会根据场景描述生成图片

### 步骤 7：生成分镜脚本

**位置**：制作页面 → 点击"生成分镜"按钮

#### 7.1 生成分镜

1. 点击"生成分镜"按钮
2. AI 会根据剧本内容，自动生成分镜脚本
3. 生成时间约 1-2 分钟

**分镜脚本包含**：

| 字段 | 说明 | 示例 |
|------|------|------|
| 分镜序号 | 分镜的顺序号 | 1, 2, 3... |
| 景别 | 镜头的景别 | 远景、全景、中景、近景、特写 |
| 运镜 | 镜头运动方式 | 推镜、拉镜、摇镜、移镜、跟镜 |
| 角色 | 分镜中的角色 | 年轻武侠弟子、神秘老人 |
| 对白 | 角色对白 | "师父，我要学武功！" |
| 画面描述 | 分镜的画面内容 | "年轻武侠弟子在山林中奔跑" |
| 视频提示词 | 用于生成视频的提示词 | "一个年轻人跑步，山林背景，动态镜头" |

#### 7.2 编辑分镜（可选）

如果对已生成的分镜不满意，可以：

1. **手动编辑**：点击分镜卡片，修改分镜内容
2. **重新生成**：点击"重新生成分镜"按钮
3. **删除分镜**：点击分镜卡片上的"删除"按钮
4. **添加分镜**：点击"添加分镜"按钮，手动添加新分镜

### 步骤 8：生成分镜图片

**位置**：制作页面 → 选择某个分镜 → 点击"生成图片"按钮

#### 8.1 生成单个分镜图片

1. 在左侧分镜列表中，选择要生成图片的分镜
2. 点击"生成图片"按钮
3. 系统会调用图片生成服务，根据分镜描述生成图片
4. 生成时间约 30秒-1分钟

**生成逻辑**：
- AI 会参考分镜描述、角色图片、场景图片
- 生成的图片会尽可能符合分镜要求

#### 8.2 批量生成分镜图片

1. 点击"批量生成"按钮
2. 系统会自动为所有未生成图片的分镜生成图片
3. 可以实时查看生成进度

**注意事项**：
- 批量生成时，建议不要关闭页面
- 如果某张图片生成失败，可以单独重新生成

#### 8.3 选择满意的分镜图片

1. 每个分镜可以生成多张图片
2. 点击分镜卡片，可以看到生成的所有图片
3. 选择最满意的一张，点击"设为主图"

---

### 步骤 9：生成分镜视频

**位置**：制作页面 → 选择某个分镜 → 点击"生成视频"按钮

#### 9.1 前提条件

- ✅ 视频生成服务已配置（AI 配置页面）
- ✅ 分镜图片已生成


#### 9.2 生成单个分镜视频

1. 在左侧分镜列表中，选择要生成视频的分镜
2. 点击"生成视频"按钮
3. 系统会调用视频生成服务，根据分镜图片和提示词生成视频
4. 生成时间约 2-5 分钟（取决于硬件和模型）

**生成逻辑**：
- **在线服务**：上传分镜图片和提示词到服务端，等待生成


#### 9.3 批量生成分镜视频

1. 点击"批量生成"按钮
2. 系统会自动为所有未生成视频的分镜生成视频
3. 可以实时查看生成进度

**注意事项**：
- 视频生成时间较长，建议耐心等待
- 如果某个视频生成失败，可以查看错误日志，然后重新生成

---

### 步骤 10：合成最终视频

**位置**：制作页面 → 点击"合成视频"按钮

#### 10.1 前提条件

- ✅ 所有分镜视频已生成
- ✅ ffmpeg 已安装（用于视频合成）

**ffmpeg 安装**：
- Windows：下载 https://ffmpeg.org/download.html，解压后添加到 PATH
- 或使用项目自带的 ffmpeg（在 `backend-node/tools/ffmpeg` 目录）

#### 10.2 合成视频

1. 点击"合成视频"按钮
2. 系统会调用 ffmpeg，将所有分镜视频合成为一个完整视频
3. 合成时间约 1-3 分钟（取决于视频数量和长度）

**合成逻辑**：
- 按分镜顺序拼接所有视频
- 添加转场效果（可在设置中配置）
- 添加背景音乐（可在设置中配置）
- 导出为 MP4 格式

#### 10.3 预览和下载

1. 合成完成后，可以点击"预览"按钮，播放最终视频
2. 点击"下载"按钮，保存视频到本地

**视频参数**：
- 分辨率：与项目画面比例一致
- 帧率：25fps 或 30fps
- 编码：H.264
- 格式：MP4

## 常见问题

### Q1：后端启动失败

**错误信息**：`Port 5679 already in use`

**解决方法**：
```bash
# 查看占用端口的进程
netstat -ano | findstr :5679

# 结束进程（将 PID 替换为实际值）
taskkill /PID <PID> /F

# 重新启动后端
npm start
```

---

### Q2：前端启动失败

**错误信息**：`Port 3013 already in use`

**解决方法**：
```bash
# 查看占用端口的进程
netstat -ano | findstr :3013

# 结束进程（将 PID 替换为实际值）
taskkill /PID <PID> /F

# 重新启动前端
npm run dev
```

---

### Q3：AI 服务连接失败

**错误信息**：`API connection failed`

**可能原因**：
1. API Key 错误
2. 服务商接口地址错误
3. 网络问题

**解决方法**：
1. 检查 API Key 是否正确
2. 检查服务商接口地址是否正确
3. 检查网络连接是否正常
4. 点击"测试连接"按钮，查看详细错误信息

---

### Q4：图片/视频生成失败

**错误信息**：`Generation failed`

**可能原因**：
1. AI 服务配额用尽
2. 生成参数错误
3. 服务暂时不可用

**解决方法**：
1. 检查 AI 服务配额是否用尽
2. 查看详细错误日志（后端控制台）
3. 等待一段时间后重试
4. 尝试使用其他 AI 服务商

---


### Q6：视频合成失败

**错误信息**：`Video composition failed`

**可能原因**：
1. ffmpeg 未安装
2. 分镜视频缺失
3. 视频格式不兼容

**解决方法**：
1. 检查 ffmpeg 是否安装（`ffmpeg -version`）
2. 检查所有分镜视频是否已生成
3. 检查视频格式是否为 MP4
4. 查看详细错误日志（后端控制台）

## 附录

### A. 配置文件说明

**位置**：`backend-node/configs/config.yaml`

```yaml
# 服务器配置
server:
  port: 5679
  cors_origins:
    - http://localhost:3013

# 数据库配置
database:
  path: ./data/drama_generator.db

# AI 服务配置
ai:
  text:
    provider: dashscope
    api_key: your_api_key
    model: qwen-max
  
  image:
    provider: dashscope
    api_key: your_api_key
    model: wanx-v1
  
  video:
    provider: agnes
    base_url: https://api.agnes-ai.cn/v1

# 存储配置
storage:
  local_path: ./data/storage
```

### C. 最佳实践

1. **首次使用**：建议先创建一个简单的测试项目，熟悉流程
2. **故事梗概**：尽量简洁明了，避免过于复杂的内容
3. **角色设计**：角色数量不宜过多（建议 3-5 个主要角色）
4. **场景设计**：场景数量不宜过多（建议每集 3-5 个场景）
5. **分镜设计**：分镜数量不宜过多（建议每集 10-20 个分镜）
6. **视频生成**：首次测试建议使用较短的分镜（5-10秒）
