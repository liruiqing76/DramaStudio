## 三、选型结论

### 推荐：Wan2.2 蒸馏4步 fp8 ComfyUI版

**理由**：
1. **速度**：4步 vs 当前20步，理论加速5倍，预计25秒/秒视频
2. **质量**：保持Wan2.2 14B画质，蒸馏后质量损失小
3. **兼容**：项目当前已用Wan2.2，换蒸馏版只需换模型文件+改步数，不动架构
4. **磁盘**：fp8版13.97GB，根目录30G可放下
5. **显存**：~14GB，4090 24GB充足

**注意**：4步蒸馏版只有I2V（图生视频）。短剧流程应为：**先用FLUX生成关键帧图片 → 再用Wan2.2蒸馏版I2V生成视频**，这正好符合短剧分镜制作流程。

### 不推荐方案及原因

| 方案 | 不推荐原因 |
|------|-----------|
| LTX-Video 2B | 质量仅⭐⭐，短剧画面糊不可用 |
| 混元1.5 720p | 65秒/秒视频，比Wan2.2蒸馏版慢2.6倍 |
| Wan2.1 1.3B | 质量差，同架构换版本无意义 |
| Wan2.2 fp16全精度 | 26.62GB，磁盘放不下 |
| Wan2.2 720p增强版 | 53GB，磁盘放不下 |

## 四、部署Wan2.2蒸馏版步骤

### 4.1 下载模型（需high_noise + low_noise两个文件）

```bash
# SSH到远程服务器
ssh -p 23156 root@connect.westb.seetacloud.com

# 下载到根目录
mkdir -p /root/wan22_distill
cd /root/wan22_distill

# 用modelscope下载（国内快）
pip install modelscope
# high_noise fp8 ComfyUI版
modelscope download --model lightx2v/Wan2.2-Distill-Models \
  wan2.2_i2v_A14b_high_noise_scaled_fp8_e4m3_lightx2v_4step_comfyui.safetensors \
  --local_dir /root/wan22_distill
# low_noise fp8 ComfyUI版
modelscope download --model lightx2v/Wan2.2-Distill-Models \
  wan2.2_i2v_A14b_low_noise_scaled_fp8_e4m3_lightx2v_4step_comfyui.safetensors \
  --local_dir /root/wan22_distill
```

总下载量：13.97GB × 2 = **27.94GB**

### 4.2 配置ComfyUI加载路径

编辑 `/root/ComfyUI/extra_model_paths.yaml`，添加：

```yaml
wan22_distill:
  unet: /root/wan22_distill
  diffusion_models: /root/wan22_distill
```

重启ComfyUI生效。

### 4.3 修改项目workflow

项目workflow文件 `backend-node/configs/comfyui_workflows/wan22_gguf_t2v.json`：
- 当前用 `UnetLoaderGGUF` 加载Q4量化模型
- 蒸馏版是safetensors格式，需改用 `UNETLoader` 或ComfyUI原生加载器
- 步数从20改为4
- 需新建 `wan22_distill_i2v.json` workflow支持两段管线（high+low noise）

### 4.4 预期性能

| 指标 | 当前(Wan2.2 Q4 20步) | 优化后(Wan2.2蒸馏4步) | 提升 |
|------|---------------------|---------------------|------|
| 单秒视频耗时 | 120s | ~25s | **4.8x** |
| 100分镜×3秒 | 10小时 | ~2小时 | 5x |
| 显存占用 | 12GB | ~14GB | 略增 |
| 质量 | ⭐⭐⭐⭐ | ⭐⭐⭐⭐ | 持平 |
