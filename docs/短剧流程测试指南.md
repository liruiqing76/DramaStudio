## 🧪 完整测试流程

### 第一步：访问应用
1. 打开浏览器访问：`http://127.0.0.1:5173`
2. 确认后端运行：`http://127.0.0.1:3013`

### 第二步：创建测试项目
1. 点击「新建项目」
2. 输入项目信息：
   - 项目名称：`测试短剧-武侠`
   - 类型：武侠
   - 集数：1集（测试用）
3. 点击「创建」

### 第三步：故事生成（文本AI）
**目的**：测试DeepSeek文本模型

1. 进入项目 → 「故事生成」
2. 输入梗概：
   ```
   现代程序员穿越到古代武侠世界，
   凭借现代知识成为一代大侠，
   最终返回现代。
   ```
3. 选择风格：「武侠」
4. 点击「AI生成故事」
5. **预期结果**：
   - ✅ 生成完整的故事大纲
   - ✅ 自动分成1集
   - ✅ 每集有详细剧本

**验证点**：
- [ ] DeepSeek API调用成功
- [ ] 故事内容符合武侠风格
- [ ] 剧本结构完整
