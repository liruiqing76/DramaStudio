【分镜要素】每个分镜聚焦一个叙事节拍（可包含内部多切镜序列），描述要详尽具体：
1. **镜头标题(title)**：用3-5个字概括该镜头的核心内容或情绪
2. **时间**：[清晨/午后/深夜/具体时分+详细光线描述]
3. **地点**：[场景完整描述+空间布局+环境细节]
4. **镜头设计**：**景别(shot_type)**、**镜头角度(angle)**、**运镜方式(movement)**
5. **人物行为**：**详细动作描述**
6. **对话/独白**：提取该镜头中的完整对话或独白内容（如无对话则为空字符串）
7. **画面结果**：动作的即时后果+视觉细节+氛围变化
8. **环境氛围**：光线质感+色调+声音环境+整体氛围
9. **声音设计**：bgm_prompt 必须填空字符串""或"无背景音乐/禁BGM"；不要为单个片段设计背景音乐。sound_effect 只写现场环境声、动作音效、对白/旁白音色与口型同步要求
10. **观众情绪**：[情绪类型]（[强度：↑↑↑/↑↑/↑/→/↓]）

**dialogue字段说明**：角色名："台词内容"。无对话时填空字符串""。
**scene_id**：从上方场景列表中选择最匹配的背景ID，如无合适背景则填null。
**duration时长**：综合对话、动作、情绪估算每镜时长（具体目标秒数由系统自动注入）。**必填，不得留空。**
**声音一致性**：所有镜头默认无BGM；若有对白/旁白，sound_effect 须补充音色与情绪强度。

**【可拍性补充要求】**
- **每个字段都要写成"可直接拍摄"的具体内容**：动作要写清主体与物理过程（谁、用身体的哪个部位、朝哪个方向、做到什么程度），禁止"情绪很复杂""气氛很紧张"这类不可成像的空话。
- **首尾帧意识**：`action` 描述的动作要能自然拆出"开始前的静止态"和"结束后的静止态"，二者产生可见变化；若一个镜头想了半天也想不出首尾差异，请把它合并进相邻镜头，而不是硬凑一个废镜头。
- **场景复用**：`location` 与 `atmosphere` 必须复用该场景已锁定的固定锚点（空间结构/材质/主色/光照基调），同一场景在不同镜头里不得出现地板材质、墙面颜色、窗户位置等本体特征的前后矛盾。
- **角色复用**：`characters` 只列本镜头真正出场的角色；其外貌、服装一律沿用已定妆的身份锚点，不得在本环节新增或改动。

【输出格式】请以JSON格式输出，包含 "storyboards" 数组。每个镜头包含：shot_number, title, shot_type, angle, time, location, scene_id, movement, action, dialogue, result, atmosphere, emotion, duration, bgm_prompt, sound_effect, characters, is_primary。**必须只返回纯JSON，不要markdown。**
